# Security

Report a vulnerability in this actor privately, through GitHub Security
Advisories on this repository. Do not open a public issue for an unfixed
defect.

## What a report here means

This repository is an assurance **scaffold**, not an accredited service.
A defect in `cyberassurance.governor` matters because a governor that fails
open lets an assurance opinion out that nobody was entitled to issue. Reports
about the governor's checks, the phase table's `:auto` sets, or the SBOM
emitter's refusals are the highest-value ones.

## What is out of scope

The actor's assessment of a third party's system is not a claim about that
system's security, and this repository is not the place to report one. It is
also not accredited: findings about *our* accreditation status are correct by
construction — see the README.
